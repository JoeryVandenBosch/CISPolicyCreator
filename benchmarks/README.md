# Benchmark packs

This directory is reserved for reviewed, public-safe benchmark pack metadata and implementations.

Only CIS benchmarks explicitly authored for Microsoft Intune are eligible.

Source PDFs and raw extracted benchmark text must never be committed here.

Current workflow targets:

- Windows 11 Intune v5.0.0
- macOS 26 Tahoe Intune v1.0.0
- iOS 17 / iPadOS 17 Intune v2.0.0
